# TheFinPedia-Executive-Dashboard

**TheFinPedia Executive Dashboard** is a Streamlit-based internal analytics platform that consolidates platform performance across three tabs:

**Revenue Tab** tracks gross earnings health — total revenue, ARPU, premium subscriber count, revenue breakdown by subscription type (Premium, Trial, Top-up), monthly revenue trend, plan-wise and partner-wise revenue contribution, and monthly-to-annual plan conversion tracking with a user-level conversion table.

**Subscriptions Tab** covers user lifecycle and retention — total registered users, premium conversion rate, renewal rate, membership distribution across Silver/Gold/Platinum/Diamond tiers split by monthly and annual billing cycles, premium users by SSO acquisition partner, user growth trend, conversion funnel drop-off analysis, renewal cohort trend, renewal rate by plan and by partner, and upcoming renewal alerts for the next 1/3/7/15 days.

**Engineering Tab** monitors software release quality — total issues, closed issues, pending backlog, reopen events, UAT verification count, and regression rate as KPIs, followed by release quality parameters audit, release-wise defect distribution across versions 9.2–UAT 9.8, issue status and severity breakdowns, classification by category and technical type, module-wise defect hotspots, high priority pending issues, issues reopened multiple times, reopen events by priority and module, page-wise issue summary, and a searchable/filterable defect registry explorer with per-issue audit trace logging.
